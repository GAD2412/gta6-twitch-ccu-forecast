Forecasts Grand Theft Auto VI's launch-day Twitch viewers for hours 2–24 (UTC) from hour 1's count. Analog method:
each past big launch in the case gives a release-day curve `log(hour h / hour 1)`; hour h's five quantiles are the
weighted empirical quantiles of those curves (midnight-local launches up-weighted, early-access and weak analogs
down-weighted), scaled by this case's hour-1 count. Python stdlib only, deterministic, well under a second.

Leave-one-out over 37 past launches: pinball loss 0.713 vs the house baseline's 0.930 (`python3 check.py input/p00.in`).

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
